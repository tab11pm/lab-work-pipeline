# lab-work-pipeline

Скилл выполнения лабораторных работ от задания до отчётов DOCX и PDF.
Работа проходит через четыре роли: Аналитик, Исполнитель, Ревьюер и Автор
отчёта. При наличии субагентов роли выполняются отдельно, иначе — последовательно.

## Установка

Клонируйте этот репозиторий или скачайте его в постоянный каталог.
Из корня репозитория выполните команды для используемого агента:

```bash
# Codex и хосты с общим каталогом скиллов
mkdir -p ~/.agents/skills
ln -s "$PWD" ~/.agents/skills/lab-work-pipeline

# Claude Code
mkdir -p ~/.claude/skills
ln -s "$PWD" ~/.claude/skills/lab-work-pipeline
```

Если хост читает только `~/.codex/skills`, создайте аналогичную ссылку там.
Если целевой путь уже существует, сначала проверьте его содержимое.
Не перемещайте исходный каталог, пока используете ссылки.

## Использование

Откройте рабочую папку лабораторной и передайте агенту методичку, вариант
и требования преподавателя. Вызовите `$lab-work-pipeline` в Codex
или `/lab-work-pipeline` в Claude Code.

Спецификация, реализация и ревью сохраняются в рабочем каталоге лабораторной,
итоговые отчёты — в `outputs/report.docx` и `outputs/report.pdf`.
Автор отчёта начинает работу после одобрения реализации Ревьюером.
Подробный процесс описан в [SKILL.md](SKILL.md).

## Инструменты и материалы

Проверьте доступность инструментов в своей среде: для отчётов могут
потребоваться LibreOffice, Poppler, архиватор и средства снимков экрана.
[toolchain.md](references/toolchain.md) описывает исходную среду;
наличие перечисленных программ на другой машине не гарантируется.

Инструкции ролей находятся в [references/roles](references/roles).
В комплект входит стандарт оформления ОС ТУСУР 01-2021:
[PDF](references/OS_TUSUR.pdf) и [текстовая версия](references/os_example.txt).
Это сторонние материалы ТУСУР; сведения об авторских правах приведены
в документе. Лицензия для собственных материалов пока не выбрана.
